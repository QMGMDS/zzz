# 硬门禁规则索引

> 本文件是规则体系的入口与路由表。规则正文按主题拆分在 `rules/` 子目录下，按需加载，不要求全量阅读。

## 文档体系

- **拆分原则**：纯按规则主题拆分，不区分代码目录；所有规则对 `Assets/_Scripts` 下的 `.cs` 全局适用。
- **执行方式标注**：`[机械 UCGxxx]` 表示 `tools/lint/lint.csx` 已覆盖该条，报错后必须修复才能过门禁；`[人工]` 表示 lint 无法机械判定，由 AI 编辑时自查。
- **与 `.editorconfig` 的分工**：editorconfig 只覆盖 IDE 层的格式与命名提示；硬门禁权威以本体系为准，机械检查以 `tools/lint/lint.csx` 为准。
- **规则编号前缀**：SCP（总则）、EDG（编辑边界）、NAM（命名）、CMT（注释）、SER（序列化）、FBD（禁止写法）、LCE（生命周期与事件）。

## 加载方式

1. **错误驱动**（修复场景）：lint.csx 报出某类 UCG 代码 → 查上表定位主题文档 → 加载后按规则条目与修复指引修复。
2. **预防驱动**（编辑前场景）：即将编辑的代码涉及敏感写法时预加载对应文档，避免违规后返工。常见映射：
   - 新增/修改 Inspector 字段 → `04-serialization.md` + `02-naming.md`
   - 订阅/退订事件 → `06-lifecycle-events.md`
   - 新增类型、公开成员、常量 → `02-naming.md` + `03-comments.md`
   - 领到任何编辑任务 → `01-edit-boundary.md`

## 机械化现状

- **已机械化（20 项）**：UCG101、102、103、104、201、202、203、302、303、304、305、306、307、308、401、402、501、502、503、601。
- **仅人工**：编辑边界（01）全部、禁止写法（05）大部分、`[Header]`/`[Range]`、Tooltip 内容质量、一字段一责任、SO 状态边界、序列化兼容确认、生命周期精确配对（LCE-02/03）、using 排序等。
- UCG301 为空缺编号，UCG000 为脚本内部默认值，均不对外使用。

## 维护规则

- **新增规则**：写入对应主题文件（必要时新建主题文件并分配新前缀），同步更新本路由表。
- **修改/删除 lint 检查项**：必须同步更新对应主题文档的映射表与"已机械化"清单。
- **人工条目机械化**：某条 `[人工]` 规则具备可机械判定条件时，应落地进 `lint.csx` 并把标注改为 `[机械 UCGxxx]`。
- 规则变更需在交付说明中向用户报备。
