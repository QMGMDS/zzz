# 编辑边界

## 定位

约束 AI 在领到编辑任务后的行为边界：改什么、不改什么、哪些改动必须先说明或先确认。所有规则与具体代码写法无关，属于任务级约束。

## 规则条目

- **EDG-01** [人工] 只修改本次任务明确要求的文件与内容。
- **EDG-02** [人工] 不得顺手修复无关问题、顺手重构无关代码、顺手格式化整个项目。
- **EDG-03** [人工] 不得新增无关文件、无关依赖、无关资源。
- **EDG-04** [人工] 不得删除、移动、重命名与任务无关的文件、对象或组件。
- **EDG-05** [人工] 不得在未说明原因时改动 public API、序列化字段、事件名、Unity 回调名、资源路径、Prefab 绑定、场景引用；涉及上述内容时必须保证兼容，不能保证兼容时先停止并说明。
- **EDG-06** [人工] 未确认影响前，不得修改 `ProjectSettings`、`Packages/manifest.json`、`Packages/packages-lock.json`。
- **EDG-07** [人工] 不得保留临时代码、调试输出、注释掉的旧实现、一次性修补代码。
- **EDG-08** [人工] 不得用"顺手"、"优化"、"整理"作为修改理由。

## 正例与反例

正例：任务要求修复 `TeamService` 的切换逻辑，只改 `TeamService.cs` 中与切换相关的代码，其他文件不动。

反例：

```text
任务：修复 TeamService 切换逻辑
违规行为：顺手把同文件内命名不规范的字段全部重命名（违反 EDG-01、EDG-05）
违规行为：顺手整理 InputBindingConfigSO.cs 的 using 顺序（违反 EDG-02）
```

## 例外情况

用户在任务中明确授权的连带修改不受 EDG-01~04 限制，但必须在交付说明中列出所有连带修改的内容。

## 与 lint 的映射表

本主题属任务级行为约束，lint 无法判定，全部依赖 AI 自查。仅 EDG-07（临时代码残留）可由 `UCG203`（TODO/FIXME/HACK/TEMP 标记）部分覆盖，详见 `05-forbidden.md`。
