# 适用范围与总则

## 定位

本文件是硬门禁规则体系的总纲：定义规则的约束对象、优先级、例外流程与严重级别。其余主题文件（01~06）只在各自范围内细化具体规则；本文件不涉及任何具体代码写法。

## 规则条目

- **SCP-01** [人工] 本规则体系只约束 AI 的编辑行为，不约束人类手工的临时排查。
- **SCP-02** [人工] 本规则体系的优先级高于个人习惯、局部示例和局部风格。
- **SCP-03** [人工] 未被明确允许的行为，一律视为禁止。
- **SCP-04** [人工] 规则以可执行、可判断、可验证为准，禁止模糊表述。
- **SCP-05** [人工] 任何一项规则无法满足时，先停止，向用户确认，不要擅自折中。
- **SCP-06** [人工] 规则例外必须显式说明例外原因与影响，并取得用户确认后方可执行。
- **SCP-07** [人工] 修改会影响序列化、引用关系或运行时行为时，必须先说明风险再执行。

## 严重级别

| 级别 | 含义 | 处理方式 |
|---|---|---|
| ERROR | 硬性违规 | 无需用户确认，AI 自行复工修复，复检通过前不得交付 |
| WARN | 风险提示 | 允许继续，但必须识别风险，且不得新增同类风险 |

## 与 .editorconfig 的分工

- `.editorconfig` 只覆盖 IDE 层的格式与命名提示。
- 本规则体系是硬门禁的权威来源，机械检查以 `tools/lint/lint.csx` 为准。
- 两者冲突时，以本规则体系为准。

## 例外情况

不存在无条件豁免。所有例外按 SCP-06 处理。

## 与 lint 的映射表

本文件为总则，无直接对应的机械检查项。
