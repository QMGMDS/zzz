# 禁止写法

## 定位

列举绝对禁止出现的代码写法与交付内容。本文件是负面清单：只要命中即违规，无条件辩解空间。命名类禁令见 `02-naming.md`，序列化类禁令见 `04-serialization.md`。

## 规则条目

- **FBD-01** [机械 UCG302] 禁止 public 字段直接暴露给 Inspector。
- **FBD-02** [人工] 禁止用注释代替代码。
- **FBD-03** [人工] 禁止注释掉旧逻辑当备份。
- **FBD-04** [机械 UCG203] 禁止保留 `TODO`、`FIXME`、`HACK`、`TEMP` 作为交付结果。
- **FBD-05** [人工] 禁止空行堆砌、无意义重排、纯格式噪音。
- **FBD-06** [人工] 禁止制造歧义的缩写、临时别名和多套命名并存。
- **FBD-07** [人工] 禁止通过"看起来更干净"而改变行为。
- **FBD-08** [人工] 禁止在未明确要求时修改场景层级、Prefab 结构、资源命名、动画状态机、事件绑定。
- **FBD-09** [人工] 禁止新增无关依赖、无关脚本、无关资源来绕过规则。

## 正例与反例

```csharp
// 反例
// public void ApplyDamage() { ... }     // 违反 FBD-03：注释掉的旧实现
// TODO: 支持暴击                        // 违反 FBD-04：TODO 残留（UCG203）



// 违反 FBD-05：空行堆砌
public void DoThing() { var t = GetData(); /* 取数据 */ return t; }  // 违反 FBD-02：注释代替代码
```

## 例外情况

无。负面清单不接受例外；若认为某条禁令不合理，按 `00-scope.md` 的 SCP-06 向用户提出修法建议，而不是绕过。

## 与 lint 的映射表

| UCG | 级别 | 规则条目 | 修复指引 |
|---|---|---|---|
| UCG203 | ERROR | FBD-04 | 删除 TODO/FIXME/HACK/TEMP，或转化为正式任务记录后移除 |
| UCG302 | ERROR | FBD-01 | 改为 `[SerializeField] private` 或属性暴露 |

注：UCG203 同属 `03-comments.md` 的 CMT-07，以本文件为权威定义、彼处交叉引用。FBD-02/03/05~09 尚无机械检查，靠 AI 编辑时自查。
